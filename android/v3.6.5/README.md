# HamiDebt Android v3.6.5

Verified in-place update for the existing HamiDebt app.

Fixes:
- Delivering melted gold against a gold debt now reduces the debt instead of increasing it.
- Cash-debt settlement by melted transfer follows the same correct debt-reduction sign.
- Melted pieces can be edited after entry (hallmark, lab, purity, weight, date, note).
- Editing gold transactions stored in cash_entries opens a gold-weight form instead of a cash form.
- Same applicationId and signing certificate as the installed app.
- versionCode 101, versionName 3.6.5.
